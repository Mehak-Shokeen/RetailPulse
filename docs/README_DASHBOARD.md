# RetailPulse Streamlit Dashboard

## Run locally

From the **RetailPulse project root** (the directory containing `requirements.txt`):

```bash
pip install -r requirements.txt
streamlit run app/streamlit_app.py
```

If your virtual environment is already set up, activate it before running the commands.

## Dashboard sections

- **Overview:** saved project-level counts, segment profiles, and recommendation evaluation.
- **Customer Segmentation:** segment profiles, customer filters, and customer-level RFM records.
- **Inactivity Prediction:** historical snapshot risk scores, selectable score variant, risk-band distribution, and customer lookup.
- **Product Associations:** filter saved rules by confidence and lift, view product descriptions, and download filtered rules.
- **Recommendations:** select products in a basket and generate recommendations from saved association rules; view offline evaluation metrics.
- **About & Methodology:** model and metric interpretation notes.

## Data and model behavior

The dashboard reads the artifacts already generated by the notebooks. It does not retrain models on startup. Inactivity scores are historical snapshot outputs; the selected snapshot date is shown in the UI. Product descriptions are mapped from `data/processed/cleaned_transactions.csv`.

## Expected project paths

The app expects the existing project layout, including:

- `artifacts/segmentation/`
- `artifacts/inactivity/`
- `artifacts/association/`
- `artifacts/recommendation/`
- `data/processed/cleaned_transactions.csv`

Keep the `app/` folder at the project root.
